# Contributing

Keyword Deck is a small local-first project. Contributions are welcome.

## Local setup

```bash
npm start
```

No dependencies are required. Node.js 22+ is the only prerequisite.

## Before opening a pull request

```bash
npm test
```

Please keep the app:

- local-first — no telemetry, hosted accounts or cloud storage;
- non-destructive — no automatic likes, comments, follows or messages;
- honest — surface source failures instead of inventing results;
- readable — Atkinson Hyperlegible, real font scaling, focus mode.

## Scope

Good areas for contributions:

- new free public discovery paths;
- better generic relevance and spam handling;
- accessibility and keyboard improvements;
- export formats and local workflow improvements.

Please do not add:

- login scraping or cookie bridges;
- private group access;
- automated engagement;
- paid APIs without an explicit opt-in and cost cap.
